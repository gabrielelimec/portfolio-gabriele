# Portfólio Pessoal — Gabriele Lima da Conceição Gomes

Portfólio online (currículo) desenvolvido para a atividade prática de **Fundamentos da Programação Web** (UNINTER).

Site de página única (Single Page) com navegação por âncoras, construído **apenas com HTML5, CSS3 e JavaScript puro** — sem nenhum framework.

## ✨ Funcionalidades

- Menu de navegação fixo e visível em todas as seções
- Menu responsivo (hambúrguer) para celular
- Alternância de **tema claro/escuro** (salva a preferência no navegador)
- 4 seções obrigatórias: **Sobre mim, Formação, Portfólio, Contato**
- Formulário de contato com **validação em JavaScript** e simulação de envio (modal de confirmação)
- Destaque automático do link da seção atual durante a rolagem
- Layout responsivo (funciona em computador, tablet e celular)
